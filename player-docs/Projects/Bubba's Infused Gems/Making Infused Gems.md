An **Infused Gem** is a gem brewed with a potion in a brewing stand, carrying that potion's effect.

## Obtaining

### Brewing

The player places a potion in a bottle slot of a brewing stand and a **base gem** in the ingredient slot, with blaze powder as fuel. As with any brew, one base gem infuses all three bottle slots.

| Bottle slot | Ingredient | Result |
|---|---|---|
| Potion (normal, splash or lingering) | Base gem | Infused Gem of that effect and form |
| Golden apple | Base gem | Infused Gem: Absorption |
| Enchanted golden apple | Base gem | Stronger Infused Gem: Absorption |
| Wither rose | Base gem | Infused Gem: Wither |
| Glowstone dust | Base gem | Infused Gem: Glowing |
| Shulker shell | Base gem | Infused Gem: Levitation |
| Sculk shrieker | Base gem | Infused Gem: Darkness |
| Echo shard | Base gem | Infused Gem: Silence |
| Chorus fruit | Base gem | Infused Gem: Ender |
| Breeze rod | Base gem | Infused Gem: Breeze |
| Heart of the sea | Base gem | Infused Gem: Conduit Power |
| Nautilus shell | Base gem | Infused Gem: Dolphin's Grace |
| Rotten flesh | Base gem | Infused Gem: Hunger |
| Pufferfish | Base gem | Infused Gem: Nausea |
| Suspicious stew of dandelion, golden dandelion or blue orchid | Base gem | Infused Gem: Saturation |
| Suspicious stew of azure bluet or open eyeblossom | Base gem | Infused Gem: Blindness |

### Base gems

The base gem sets the gem's **Infusion level**, which affects strength only.

| Infusion | Base gem |
|---|---|
| I | Amethyst shard |
| II | Nether quartz |
| III | Ender pearl |
| IV | Diamond |
| V | Prismarine shard |
| VI | Nether star |

## Properties

- **Effect**: from the potion or item used.
- **Potion strength**: a strong (glowstone) potion makes a stronger gem, a long (redstone) potion a slightly stronger one.
- **Form**: normal, splash or lingering. The form is the potion's form and can't be changed after brewing. It sets the highest enchanting tier: normal reaches tier 1, splash tier 2, lingering tier 3. Items in the bottle slot (golden apples, wither roses, stews and the rest) have no form: their Infused Gems show no form in the name, for example *Infused Gem: Infusion IV, Absorption*, and reach tier 3 like a lingering potion's. Collecting the items is the cost. *Main article: [[Enchanting Gems]]*

The item name shows these, for example *Infused Gem: Infusion III, Speed (Splash)*.

## Supported potions

Every potion: Swiftness, Strength, Leaping, Regeneration, Turtle Master, Fire Resistance, Water Breathing, Night Vision, Invisibility, Slow Falling, Luck, Healing, Poison, Slowness, Weakness, Harming, Wind Charged (it makes a **Wind Burst** gem), Weaving, Oozing and Infested, plus the items in the table above. A Turtle Master potion makes a **Turtle Master** gem, which gives its Resistance and its Slowness together. The Luck potion has no survival recipe, so Luck gems are mostly found. Haste, Health Boost, Hero of the Village, Mining Fatigue and Resistance gems have no brewing source and are only found in the world. *Main article: [[Finding Gems]]*

A suspicious stew counts by its effect, so any stew with the Saturation or Blindness effect of those flowers works; other stews do not.

## Notes

- A hopper on the side of a brewing stand also pushes these items (golden apples, wither roses, glowstone dust, rotten flesh and the rest) into the bottle slots.
