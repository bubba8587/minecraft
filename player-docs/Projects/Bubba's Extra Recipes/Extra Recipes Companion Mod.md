The **Extra Recipes Companion Mod** is the Fabric mod version of [[Bubba's Extra Recipes]].

- Contains the [[Recipe List|recipes]] and the resource pack, so only one file (plus Fabric API) is installed.

## Installation

*Main article: [[Installing Fabric Mods]]*

- Must be installed on **both the server and every player's game**.
- A player who joins a server without it is told to install it.

## Features

- **[[The Glider]]**: a craftable glider that handles worse than an elytra and wears out a little sooner.
- **Quartz Shards**: andesite, diorite and granite blast into a Quartz Shard in a blast furnace; four shards in a square craft one nether quartz.
- **[[Synthetic Diamond Ore]]**: placed ore from the blast-furnace recipe rarely drops a diamond when mined.
