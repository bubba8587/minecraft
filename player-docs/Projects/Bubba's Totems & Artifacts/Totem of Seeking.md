The **Totem of Seeking** is an artifact that points toward the nearest structure of a chosen kind, like a compass.

## Obtaining

The Totem of Seeking cannot be crafted. It is found in shipwreck map chests, buried treasure, big ocean ruins and village cartographers' houses, and in [[Relic Vaults|relic vault]] chests. It is also found in trial chamber vaults: a 0.7 % chance each time a player opens a normal vault, and 1.4 % for an ominous vault.

A [[Relic Vaults|relic vault's]] pedestal may also hold a Totem of Seeking [[Totem Statue|statue]]; breaking the statue gives the totem.

## Usage

### Choosing a structure

Using the totem on a structure's typical block (placed anywhere) makes it seek that kind of structure. A lodestone sound plays and a message such as "Seeking: Jungle Temple" appears; the tooltip then reads "Seeks: Jungle Temple". Using it on any other block does nothing.

| Structure | Block to use it on |
|---|---|
| Village | Hay bale or bell |
| Desert pyramid | Chiseled sandstone |
| Jungle temple | Mossy cobblestone |
| Swamp hut | Cauldron |
| Igloo | Snow block |
| Pillager outpost | Dark oak log |
| Woodland mansion | Dark oak planks |
| Ocean monument | Prismarine, prismarine bricks, dark prismarine or sea lantern |
| Ruined portal | Crying obsidian |
| Mineshaft | Rail |
| Abandoned camp | Campfire |
| Trail ruins | Decorated pot |
| Stronghold | Cracked or chiseled stone bricks |
| Trial chambers | Tuff bricks or chiseled tuff bricks |
| Ancient city | Reinforced deepslate or sculk shrieker |
| Nether fortress | Nether bricks or nether brick fence |
| Bastion remnant | Gilded blackstone or polished blackstone bricks |
| End city | Purpur block or purpur pillar |

Shipwrecks, ocean ruins, buried treasure, nether fossils and [[Relic Vaults|relic vaults]] cannot be sought.

### Pointing

Anywhere in the inventory, the totem's needle points to the nearest structure of its kind, like a lodestone compass. The needle spins while nothing is chosen, while the first search is still running, and when there is no such structure in the current dimension (for example a nether fortress sought from the Overworld). Once the player reaches the structure, the totem keeps pointing at it.

### In a beacon

In a [[Bubba's Reworked Beacons]] beacon, every ordinary compass held in the beacon's area points to the nearest structure of the totem's kind, searched from the beacon.

- The compass shimmers like a lodestone compass but keeps the name "Compass".
- It turns back into a plain compass about 5 seconds after it leaves the area.
- Compasses already bound to a lodestone are left alone.

The beacon screen reads, for example, "Compasses point to the nearest Jungle Temple". A totem with no structure chosen does nothing in a beacon.

## Statue

Sneaking and using the totem on a block sets it down as a [[Totem Statue]] instead of choosing a structure. The statue has no effect. Mining it gives the totem back.
