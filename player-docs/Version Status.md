# Version Status

**Current Minecraft version: 26.3** (released 2026-09-15)

**Version Status** lists the Minecraft version the projects target and any project paused on it.

- Every project moves to each new Minecraft release as soon as possible.
- A project that is not ready (for example, because a library it needs has not updated) is **paused** on the new version until it is, and is listed below with the reason.
