# Installing Resource Packs

This tutorial explains how to turn on a resource pack. Resource packs change how the game looks and sounds: textures, models, sounds and text.

1. Open **Options**, then **Resource Packs**, then click **Open Pack Folder**.
2. Place the pack's `.zip` in that folder.
3. Back on the Resource Packs screen, move the pack to the right-hand (selected) side and click **Done**.

When two packs change the same thing, the pack higher in the list takes priority.

Resource packs built into a mod, such as a mod's 32x textures, need no file: they already appear in the Resource Packs list once the mod is installed.
