# Installing Resource Packs

Resource packs change how the game looks and sounds: textures, models, sounds and text.

1. Options, then **Resource Packs**, then **Open Pack Folder**.
2. Put the pack's `.zip` in that folder.
3. Back in the Resource Packs screen, move the pack to the right-hand (selected) side and click Done.

Packs higher in the list win when two packs change the same thing.
