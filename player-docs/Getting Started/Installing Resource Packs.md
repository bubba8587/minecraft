# Installing Resource Packs

This tutorial explains how to turn on a resource pack.

- Resource packs change how the game looks and sounds: textures, models, sounds and text.

1. Open **Options**, then **Resource Packs**, then click **Open Pack Folder**.
2. Place the pack's `.zip` in that folder.
3. Back on the Resource Packs screen, move the pack to the right-hand (selected) side and click **Done**.

- When two packs change the same thing, the pack higher in the list takes priority.

## Bubba's Mods 32x

- One resource pack with the 32x textures of all of Bubba's mods, in the style of Classic Faithful 32x Jappa.
- Its zip is downloaded from the project's GitHub Releases and installed like any resource pack.
- It goes above Classic Faithful 32x Jappa when both are used.
- Textures for mods that aren't installed are simply unused.
