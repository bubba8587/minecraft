# Installing Datapacks

Datapacks change the game using Minecraft's own built-in tools, so no mod loader is needed. They're added per world.

## New world

1. Create New World, then the **More** tab, then **Data Packs**.
2. Drag the datapack's `.zip` into the window, then move it to the right-hand (selected) side.
3. Create the world.

## Existing world

1. Open the world's folder: in the world list, select the world, Edit, Open World Folder.
2. Put the `.zip` in the `datapacks` folder.
3. In-game, run `/reload` (or reopen the world). Some packs that add things like new dimensions or biomes need the world reopened.

`/datapack list` shows which packs are active.

## Servers

Put the `.zip` in the server's `world/datapacks` folder and restart the server or run `/reload`.
