# Bubba's Mods 32x

One resource pack with the 32x textures (Classic Faithful 32x Jappa style) of all of Bubba's mods. Put it above Classic Faithful 32x Jappa (or another 32x pack) in the Resource Packs screen.

The art is not kept here: each mod's 32x set lives in `mods/<modid>/src/main/resources/resourcepacks/<modid>_32x/`, and `python3 tools/pack.py build bubbas_32x` collects them (the `COMBINE` file) into `build/packs/resourcepacks/bubbas_32x-<VERSION>.zip`. Credits: `CREDITS.md` (shipped in the zip).
