## Decision

Before relying on a Minecraft or Fabric API name, an agent checks it against the decompiled source of the target version or the Fabric API branch for it. The knowledge base in docs/knowledge is written the same way.

## Why

Minecraft renames and reshapes APIs every release, and memory from older versions is the main source of code that does not compile or silently misbehaves.
