## Decision

Before designing a mod, pack or tool, an agent searches Modrinth and GitHub for existing projects that already do it or part of it. Existing libraries and tools are used instead of re-implementing them, existing open-source mods are studied for how they solve the same problem, and a new project that mostly duplicates an existing one is flagged to the owner before work starts.

## Why

The owner asked for it: "lots of Minecraft mods already exist, please be sure to use existing knowledge instead of duplicating work." Written by the agent from that instruction; awaits ratification.
