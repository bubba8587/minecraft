# Textures: 16x and 32x

Every custom texture exists twice: a 16x version in vanilla style and a 32x version in the style of Faithful 32x. Each 32x texture is exactly twice the width and height of its 16x twin and has the same path.

**Mods.** The 16x set is the mod's normal assets, `src/main/resources/assets/<modid>/textures/...`. The 32x set is a built-in resource pack inside the same jar at `src/main/resources/resourcepacks/<modid>_32x/`, with its own `pack.mcmeta` and the same `assets/<modid>/textures/...` paths. The mod registers it on the client with `ResourceLoader.registerBuiltinPack(Identifier.fromNamespaceAndPath(MOD_ID, MOD_ID + "_32x"), container, PackActivationType.NORMAL)` and a display name ending in "32x (Faithful style)", so players switch it on in the Resource Packs screen, above Faithful 32x if they use it.

**Resource pack projects.** `resourcepacks/<name>/` is the 16x pack and `resourcepacks/<name>-32x/` the 32x pack, released together.

**Animations and metadata.** A `.png.mcmeta` next to a 16x texture has a matching one next to its 32x twin; frame counts and timing match.

**Checking.** `python3 tools/texcheck.py` fails when a 16x texture has no 32x twin, a twin is not exactly double size, or the animation metadata doesn't match. Projects with `internal=true` in `gradle.properties` (refmod) are skipped; their textures are placeholders.

**Credit.** A project with Faithful-derived textures has a `CREDITS.md` naming what was used and linking https://faithfulpack.net, and its player docs page and Modrinth listing carry the same credit.

**Who makes them.** Textures are images, so they are made by people or derived from human-made art, never generated by AI.
