# Player docs vault

`player-docs/` is an Obsidian vault of player-facing documentation, separate from `decisions/`, `specs/`, `docs/knowledge/` and code. Notes in it carry no `dte:` citations and no implementation detail: this spec is how the vault cites what it serves.

Every project players can get has a page in `player-docs/Projects/`, started from the matching template in `player-docs/Templates/`, with frontmatter `type`, `minecraft`, `status` (`active` or `paused`) and `modrinth`. Internal projects (`refmod`, `refpack`) get no page.

A change that alters what players see (a feature, a command, a keybind, a config option, a dependency, the supported Minecraft version) updates the project's page in the same change.

`Version Status.md` names the current Minecraft version and lists every project that is paused on it, with a plain reason (B10 alwaysLatest).

Pages use plain language: what it does, how to use it, what it works with. Specs say how things are built; the vault says how to use them. Images in the vault are made by people, never generated by AI.

`Home.md` links every project page and the getting-started guides.
